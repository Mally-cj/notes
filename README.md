# 关于我 (About Me)

你好！我是**陈洁**，目前是西安交通大学的三年级硕士研究生，十分荣幸师从[高静怀教授](https://baike.baidu.com/item/%E9%AB%98%E9%9D%99%E6%80%80/1262674)和[陈红灵老师](https://gr.xjtu.edu.cn/en/web/chenhongling)。

我的核心研究课题为**基于扩散模型的波阻抗反演**，同时我对人工智能（AI）的前沿技术及其落地应用充满热情。在未来的学术与职业生涯中，我期待在以下领域进行更深入的探索：

- **扩散模型在逆问题中的应用** (Diffusion Models for Inverse Problems)
- **LLM应用** (LLM Applications)
- **智能体研究** (AI Agents)
